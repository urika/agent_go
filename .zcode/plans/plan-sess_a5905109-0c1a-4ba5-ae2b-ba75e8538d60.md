# S9-A MCP 消费层实现计划

## 目标
让 agent_go 子任务能调用用户配置的外部 MCP server 工具（如 excel-mcp-server、office-powerpoint-mcp-server），覆盖 AgentLoop 和 claude CLI 两条执行路径，兼容 MCP 标准和 agent_go 自有的两种结果格式。

## 设计决策（已确认）
- **双路径接入**：AgentLoop（进程内工具合并+dispatch 路由）+ claude CLI（`--mcp-config` 透传）
- **结果格式兼容**：先尝试 `result.content[].text`（MCP 标准），不存在则当裸 dict
- **零外部依赖**：用 stdlib 实现 JSON-RPC over stdio（与 mcp_server.py 一致）
- **故障隔离**：server 启动失败降级 warning 不阻断 pipeline（与 notify/skills 同级）

## 文件变更清单（6 个文件）

### 1. 🆕 `agent_go/mcp_client.py`（核心新模块，~280 行）

```
MCPServerConnection          # 单 server 生命周期
├── __init__(name, spec)     # spec = {command, args, env, enabled, tool_filter, scope}
├── start()                  # Popen + JSON-RPC initialize 握手（超时 10s）
├── list_tools() -> list     # tools/list → 过滤 tool_filter → 加 mcp__{name}__ 前缀
├── call_tool(tool, args)    # tools/call → 解析结果（兼容 content blocks + 裸 dict）
└── stop()                   # terminate → wait(3s) → kill（复用 mcp_server.py:970 模式）

MCPClientPool                # 多 server 连接池
├── __init__(server_configs: dict)
├── start_all()              # ThreadPoolExecutor 并发启动，per-server try/except 降级
├── tool_definitions() -> list   # 合并所有 server 工具（命名空间前缀）
├── dispatch(full_name, args)    # 按 mcp__{server}__{tool} 拆分路由
├── mcp_config_for_claude() -> dict  # 生成 claude --mcp-config 透传的 JSON
└── stop_all()               # 并发 stop，finally 保证回收
```

**协议实现要点**（基于现有 mcp_server.py 探索）：
- NDJSON framing：`json.dumps(msg, ensure_ascii=False) + "\n"` 写 stdin，按行读 stdout
- initialize：发 `{method:"initialize", params:{protocolVersion:"2024-11-05", capabilities:{}}}`，读 result 含 `protocolVersion`/`capabilities`/`serverInfo`
- 请求/响应匹配：用自增 int id + `threading.Event` + `_pending: dict[id, Event]` + `_results: dict[id, result]`（复用 mcp_server.py:1390-1414 deferred 模式）
- 后台 reader 线程：读 stdout 每行 → json.loads → 按 id 路由到 _pending Event 或丢弃 notification
- stderr drain 线程：daemon，丢弃（复用 mcp_server.py:407-415 `_drain_stderr`）
- 结果解析：`_parse_result(result)` → 若有 `result.get("content")` 取 `content[0].text`（MCP 标准），否则 `json.dumps(result)`（裸 dict）
- logger：`logging.getLogger("agent_go.mcp.client")`

```python
if _mcp_cfg:
    try:
        from .mcp_client import MCPClientPool
        mcp_pool = MCPClientPool(_mcp_cfg)
```

```python
# S9-A: 透传外部 MCP server 配置给 claude CLI（claude 原生支持 MCP 消费）
_mcp_pool = env.get("_AGENT_GO_MCP_POOL", None)  # 由 executor 注入标记
if _mcp_pool:
    import tempfile, json as _json
    _mcp_cfg = _mcp_pool.mcp_config_for_claude()
    if _mcp_cfg.get("mcpServers"):
        with tempfile.NamedTemporaryFile(mode="w", suffix=".json", delete=False) as _tf:
            _json.dump(_mcp_cfg, _tf)
            cmd.extend(["--mcp-config", _tf.name])
```

## 验收标准（对齐设计稿 §5.1）
- A1: 配置 mcp_servers 后 AgentLoop tools 列表含 `mcp__excel__*`
- A2: server 启动失败时降级 warning，pipeline 正常完成

- A5: tool_filter 白名单生效

## 风险与对策
| 风险 | 对策 |
|------|------|
| 外部 server 稳定性参差 | per-server try/except 降级 |
| 进程泄漏 | finally 强制 stop_all + terminate→kill |
| 工具 schema 爆炸吃 token | tool_filter 白名单 |
| claude CLI --mcp-config 临时文件 | NamedTemporaryFile + 用完清理 |
