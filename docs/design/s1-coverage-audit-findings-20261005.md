## 0. 结论先行（**v0.3 修正**：缺口效应被同批同模型对照推翻；成立的是"告警"的区分度）

1. **修正：缺口效应不成立**——v0.2 的"模型内 OR=2.51"是**年代混杂**：缺口样本 **98% 集中在 5 个旧文件**（v3/旧 results/orig/v4_calib/v5_smoke，旧批缺 plan telemetry），而"有输出"样本主要在 2026-08 之后批次。唯一能做**同批同模型**对照的批次（`results.jsonl`×claude-sonnet）：缺口 **29%(n48) vs 有输出 29%(n150)，OR=0.99，p=0.87** ⇒ **"规则没输出"应读作仪表缺口，不是风险信号**；
2. **成立的是"告警"的区分度**（同批同模型内）：`warning vs passed` —— sonnet **34%(87) vs 22%(63)**、deepseek-flash **57%(37) vs 20%(137)** ⇒ **"规则不确定"的群体才是真缺口**；
3. **难度分层结论同样降级**：gap 组逐层更差受同一年代混杂影响，只作参考（见 §1 D 注）；
4. **两个伪迹定案（v0.2 保持）**：`lint_errors=0`＝"lint 未运行"伪迹（92.2% 从未 completed，**字段弃用**）；warnings 3+ 回落＝地板批次混合效应（剔除后恢复单调 19.1% < 30.2% < 33.9%）；
5. **一个靶缺口实锤**：验收/需求覆盖字段 **0/1701 从未产出**；
6. **"rules+jev" 仍不可验证**——历史无 jev 数据，须等试点（v1.4 已登记）。

## 2. 解读（[分析]）

- **修正后的实证支点（v0.3）**：同批同模型内 `warning` 组失败率显著高于 `passed`（sonnet +12pp、deepseek +37pp）⇒ "**规则不确定的地方更容易出问题**"——S-1 的映射应挂在"**warning（规则不确定）**"上，而不是"None（仪表缺口）"；
- 原"缺口单调性（16% < 23.8% < 30%）"**作废为年代构成效应**（见 §F2）；地板效应依然说明规则判别力绑定"难度×模型"区间；
- `plan_acceptance_coverage` 从未产出，意味着"覆盖度"目前只是人工判断——**S-1 的价值起点就是把这一列真正填上**。

## 3. 局限与边界

1. **回顾性**：只证关联，不证因果；**缺口效应经同批同模型对照后不成立（v0.3 修正）**——"None"主要是旧批仪表缺口；当前可用的正向结论只有 **warning vs passed 的区分度**（同批同模型内 +12~37pp）；
2. **无 jev 数据**：本件是"规则侧"自证；"rules+jev"版本须等试点产出（v1.4 §18 已登记）；
3. **伪迹已定案**（v0.2）：`lint_errors=0`＝"lint 未运行"伪迹（**弃用该字段**）；warnings 3+ 回落＝地板批次混合效应（**引用 3+ 时须声明批次口径**）；
4. 本件不得进任何 verdict/门槛——它只回答"该给哪里补规则/补测试"。
