# 摘要

D-1 阶段对四个信任指标进行放行评估，结论为**不放行**。当前四指标中仅返工率达标（3.8%，已达成熟期线），其余三项均不达标：盲区命中率 0/37（低于 50% 下限，标注口径过保守）、复发可见率窗口内样本过小（n=1）、审查后修改率样本不足（n=3<10）。

相较 D-0，机制已全部接线、样本已积累，暴露的问题从「缺数据」转为「盲区标注口径过保守」，这是放行前必须解决的口径问题。

**信任指标**指返工率、复发可见率、审查后修改率、盲区命中率四项，用于从质量、稳定性、可追溯性、盲区覆盖四个维度量化 Agent 表现，并对照 D-0 提案阈值判定是否达标。

**放行门**是阶段 D 的放行评估——经 A1 口径修复（收紧盲区命中规则、新增观察期证据、pending 项移出分母）后，盲区指标由「恒 0 失灵」转为「口径健全 + 待观察期成熟」，A1 解除阻塞；放行条件更新为 A2 攒 ≥10 个 review 决策 + A3 攒 ≥5 个失败子任务 + 盲区指标攒 ≥20 条已判定标注，并用测试用例验证各分支逻辑。
